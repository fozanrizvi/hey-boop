# HeyBoop

A baby learning tap game for toddlers (12 months – 3 years). Tap anywhere on the screen and something delightful happens — a giant number, letter, or animal pops up with a cheerful voice saying it aloud. Built as a progressive web app installable from the home screen on any iOS or Android device.

**Live demo:** https://heyboop-449.netlify.app

---

## What it does

- **Tap anywhere** → a giant item pops on screen with a spring animation and a voice saying its name
- **Numbers 1–10** — the numeral fills the screen; count objects (apples/stars) pop in one by one beneath it
- **ABC A–Z** — giant letter with the letter name spoken clearly
- **Animals** — big illustration + spoken name; tap again for the animal sound ("Cow!" → tap → "Moo!")
- **Fruits & Vegetables** — big illustration + spoken name
- Loops forever: 10 → back to 1, Z → back to A — no win screens, no progression pressure
- **Parent gate** — hold the exit button for 3 seconds (with a filling ring) to leave play mode; quick taps do nothing so toddlers can't escape

---

## Design principles

1. **Tap-anywhere** — babies can't hit small targets; the entire play area is one big button
2. **One thing on screen** — high contrast, bright, zero clutter during play
3. **Voice is the product** — audio triggers instantly on finger-down, not click
4. **Repetition is the feature** — no timers, streaks, or notifications
5. **Kid-proof by design** — no links out, no accidental exits, no double-tap zoom, no scroll bounce
6. **Zero data collection** — no analytics, no accounts, no network calls after the initial load

## Replacing the placeholder voice recordings

The app ships with Windows TTS placeholder MP3s. Recordings play through Web Audio, which is exempt from the iOS hardware silent switch — the TTS fallback stays muted in silent mode. Recording real files is the single biggest quality upgrade.

Drop replacements at these paths (no code changes required):

```
public/audio/numbers/1.mp3 … 10.mp3     "One!" … "Ten!"
public/audio/abc/a.mp3 … z.mp3          letter names
public/audio/animals/cow.mp3            "Cow!"
public/audio/animals/cow-sound.mp3      "Moo!"
public/audio/fruits/apple.mp3           "Apple!"
… and so on for each item
```

See `public/audio/README.md` for full path list and recording tips (warm/cheerful, trimmed silence, mono, normalised).

## Adding a new content pack

The engine is fully data-driven. Adding a pack requires **zero engine changes**:

1. Create `src/packs/yourpack.ts` implementing `ContentPack`
2. Add illustrations to `src/assets/svg/` and register them in `illustrations.ts`
3. Add one line to `src/packs/index.ts`
4. Drop audio files under `public/audio/yourpack/`

The Home screen card and all tap/audio/animation behaviour come for free.

```ts
// Minimal pack example
export const colorsPack: ContentPack = {
  id: 'colors',
  title: 'Colors',
  icon: '🎨',
  loop: true,
  items: [
    { id: 'red',  display: '',    label: 'Red',   color: '#FF6B6B', audio: '/audio/colors/red.mp3' },
    { id: 'blue', display: '',    label: 'Blue',  color: '#4ECDC4', audio: '/audio/colors/blue.mp3' },
    // …
  ],
}
```

## Audio architecture

Audio reliability on iOS Safari required several non-obvious fixes:

- **`navigator.audioSession.type = 'playback'`** — exempts the AudioContext from the hardware silent switch (iOS 16.4+). Without this, all Web Audio is muted in silent mode.
- **TTS unlock inside a gesture** — a muted `SpeechSynthesisUtterance` must be spoken inside the very first user gesture, or speech synthesis silently fails on iOS.
- **No idle `cancel()`** — calling `speechSynthesis.cancel()` when nothing is queued poisons the next `speak()` call on iOS. The engine only cancels when `speaking || pending` and defers the next speak 60 ms after any cancel.
- **Utterance ref** — Safari garbage-collects `SpeechSynthesisUtterance` objects mid-queue unless a JS reference is held.

All audio is routed through a master `GainNode` so the volume setting takes effect instantly without restarting any buffers.

## PWA / offline

The service worker precaches all 114 assets (~7.7 MB) including every MP3, font, and SVG so the app works in airplane mode after the first visit. Manifest has `display: fullscreen` so it hides the Safari chrome when launched from the home screen.

To regenerate icons and splash screens (e.g. after changing the mascot):

```bash
node scripts/generate-assets.mjs
```
